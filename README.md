# SkillLink — Worldwide Home & Professional Services Marketplace

SkillLink is a modern, responsive, and lightweight digital marketplace that connects customers worldwide with skilled tradespeople, technicians, and specialized service professionals across 10 core sectors.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Library**: React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS (with custom Emerald, Soft Mint, and Gold tokens)
- **Icons**: Lucide React
- **Animations & Effects**: Framer Motion, HTML5 Canvas Network visual, Canvas Confetti, and Cursor-following Card Glow
- **State & Architecture**: React Context with LocalStorage sync and typed Mock Stores (prepared for Supabase integration)

## 10 Core Service Categories (71 Total Services)

1. **Home & Repair** — Plumber, Electrician, Carpenter, Painter, Mason/Construction, Handyman, Door & Lock Repair, Window & Glass Repair, Roof Repair, General Home Repair.
2. **Electrical & Appliances** — AC Technician, Refrigerator Repair, Washing Machine Repair, Gas Stove Repair, Water Heater/Geyser, TV Repair, Generator Technician, Solar Technician.
3. **Computer & Technology** — Computer Repair, Laptop Repair, Printer Repair, Wi-Fi/Network Technician, CCTV Technician, Cable Technician, Mobile Repair, IT Support.
4. **Outdoor & Garden** — Gardener/Mali, Tree Service, Landscaping, Pool Cleaning, Irrigation Technician.
5. **Cleaning** — Home Cleaning, Sofa Cleaning, Window Cleaning, Carpet Cleaning, Deep Cleaning, Waste Removal, Sewerage/Drain Cleaning.
6. **Vehicle Services** — Car Mechanic, Tyre Service, Battery Service, Car Wash, Car Detailing, Motorcycle Repair, Towing.
7. **Personal & Lifestyle** — Tailor, Hairdresser/Barber, Makeup Artist, Beautician, Photographer, Videographer.
8. **Moving & Delivery** — Movers, Packing Service, Local Delivery, Furniture Moving, Storage Service.
9. **Home Support** — Babysitter, Elderly Care, Pet Care, Dog Walker, Housekeeper, Cook/Chef.
10. **Professional Services** — Web Developer, Graphic Designer, Typing/Data Entry, Tutor, Accountant, Legal Consultant, Business Consultant.

## Quick Start (Run Locally)

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
